# Networking

My networking learning repository documenting hands-on labs, Packet Tracer configurations, and networking concepts learned through **CIS 160 – Network Foundations at Highline College** and **Cisco Networking Academy (NetAcad)**.

The main focus of this repository is building practical networking skills through **Cisco Packet Tracer labs** and documenting the work completed in each lab.

## 📚 Learning Sources

* **CIS 160 – Network Foundations**
* **Cisco Networking Academy (NetAcad)**
* Independent networking practice

## 🧪 Repository Structure

Each lab has its own folder containing:

* The completed **Cisco Packet Tracer `.pkt` file**
* The corresponding **PDF lab guide**

```text
Networking/
│
├── README.md
│
├── CIS160-LAB1/
│   ├── CIS160-LAB1.pkt
│   └── CIS160-LAB1-Lab-Guide.pdf
│
├── CIS160-LAB2/
│   ├── CIS160-LAB2.pkt
│   └── CIS160-LAB2-Lab-Guide.pdf
│
├── CIS160-LAB3/
│   ├── CIS160-LAB3.pkt
│   └── CIS160-LAB3-Lab-Guide.pdf
│

```

Additional labs will be added as I progress through my coursework and networking studies.
