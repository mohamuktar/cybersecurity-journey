# Lab 4: Design and Implement VLSM Addressing

## Objective

Design and implement a VLSM addressing scheme using the `10.1.1.0/24` network to support four LANs and a point-to-point WAN connection.

## Tasks Completed

- Designed subnets based on host requirements.
- Configured IP addresses and subnet masks on routers, switches, and PCs.
- Configured default gateways.
- Tested network connectivity and troubleshot issues.

## Subnet Allocation

| Network | Subnet |
| --- | --- |
| ES-1 LAN | `10.1.1.96/28` |
| ES-2 LAN | `10.1.1.64/27` |
| WS-1 LAN | `10.1.1.112/29` |
| WS-2 LAN | `10.1.1.0/26` |
| WAN Link | `10.1.1.120/30` |

## Key Takeaway

Learned how to use VLSM to allocate IP addresses efficiently, configure network devices, and verify connectivity between networks.
