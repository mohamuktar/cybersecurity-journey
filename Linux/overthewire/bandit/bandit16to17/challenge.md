# Bandit Level 16 → 17

## Objective

A port in the range 31000 to 32000 on localhost speaks SSL and will return the next credentials. Scan the range to find open ports, identify which one uses SSL, and connect to it to receive an SSH key.

## Skills

- nmap
- openssl
- port scanning
