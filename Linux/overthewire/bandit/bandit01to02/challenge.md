# Bandit Level 1 → 2

## Objective

The password sits in a file whose name is a single dash (`-`). Because a leading dash is interpreted as a command option, the file must be referenced with a path prefix so tools read it as a file rather than a flag.

## Skills

- cat
- file paths
- shell argument parsing
