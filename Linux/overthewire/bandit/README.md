# OverTheWire Bandit

This directory documents my progress through the
[OverTheWire Bandit](https://overthewire.org/wargames/bandit/) wargame as part of
my Linux and cybersecurity learning journey. Bandit builds the foundational
command-line, filesystem, and security skills needed to take on more advanced
wargames and CTF challenges.

---

## Structure

Every level has its own folder containing:

- **challenge.md** — A concise summary of the objective.
- **mynotes.md** — My personal notes, commands used, walkthrough, explanations, and lessons learned.
- **screenshots/** — Terminal screenshots captured while solving the level.
