# Bandit Level 23 → 24

## Objective

A cron job periodically runs every script placed in a specific directory as the next user, then deletes it. Write a script that copies the next password to a location you can read, drop it in that directory, and wait for the job to run it.

## Skills

- cron
- bash scripting
- permissions
