# Bandit Level 20 → 21

## Objective

A setuid binary connects to a port you specify and, if it receives the current password, replies with the next one. Set up a listener that serves the current password, then run the binary pointed at your port.

## Skills

- netcat
- nc
- setuid
- background jobs
