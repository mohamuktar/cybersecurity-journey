# Bandit Level 25 → 26

## Objective

Logging in as bandit26 does not give a normal shell because the account uses a pager as its login shell. Shrink the terminal so the pager pages its output, then escape from the pager into an editor to break out.

- SSH
- more
- vi
- shell escaping
