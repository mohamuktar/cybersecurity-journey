# Bandit Level 12 → 13

## Objective

The password is inside `data.txt`, which is a hexdump of a file that has been compressed repeatedly with several different tools. Reverse the hexdump, then unpack each compression layer in turn until the plaintext appears.

## Skills

- xxd
- gzip
- bzip2
- tar
- mkdir
- mv
