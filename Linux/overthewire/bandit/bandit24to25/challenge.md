# Bandit Level 24 → 25

## Objective

A daemon on port 30002 returns the next password only when given the current password followed by a secret 4-digit pincode. Since there is no shortcut, script a brute-force that submits every combination.

## Skills

- netcat
- bash loops
- brute force
