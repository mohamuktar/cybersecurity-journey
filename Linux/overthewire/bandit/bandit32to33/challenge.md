# Bandit Level 32 → 33

## Objective

After logging in you land in an 'uppercase shell' that converts every command you type to uppercase, so normal commands fail. Exploit shell variable expansion to spawn a normal shell and read the password.

## Skills

- shell escaping
- $0
- environment variables
