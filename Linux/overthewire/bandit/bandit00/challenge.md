# Bandit Level 0

## Objective

Connect to the Bandit game server over SSH to reach the first level. The host is bandit.labs.overthewire.org on port 2220, and the username and password are both `bandit0`. The goal is simply to establish the SSH session and land in the level's home directory.

- SSH
