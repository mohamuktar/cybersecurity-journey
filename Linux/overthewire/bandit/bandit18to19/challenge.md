# Bandit Level 18 → 19

## Objective

The password is in `readme` in the home directory, but the account's `.bashrc` logs you out immediately on an interactive login. Run a non-interactive SSH command to read the file before the shell exits.

## Skills

- SSH
- non-interactive shell
